# Caddy-dns-he

This repository builds a Docker image containing a custom caddy which includes [HE DNS plugin](https://github.com/caddy-dns/he).

The resulting Docker image is available via GHCR e.g.

```
docker pull ghcr.io/porjo/caddy-dns-he:v2.11.2
```

Git tags on this repository match upstream Caddy version.
